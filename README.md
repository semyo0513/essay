# ✏️ 창순기획 글쓰기 코칭 시스템

> Google Apps Script + Gemini AI 기반 중학교 글쓰기 코칭 웹앱  
> 학생이 단계별로 개요를 작성하고, AI 코치의 피드백을 받아 글을 완성합니다.

---

## 📌 주요 기능

| 기능 | 설명 |
|---|---|
| 📝 단계별 글쓰기 코칭 | 개요 작성 → 개요 수정 → 초고 → 제출 → 고쳐쓰기 → 최종 제출 |
| 🤖 AI 챗봇 코치 | Gemini API 기반 단계별 맞춤 피드백 |
| 📚 4가지 글쓰기 유형 | 주장하는 글 / 설명하는 글 / 감상문 / 정보전달글 |
| 💾 자동 저장 | 구글 시트에 실시간 기록 (학년·반·번호·이름별) |
| 🔄 이어쓰기 | 로그인 시 이전 작업 단계 자동 복원 |
| 🗂️ 관리자 모드 | 학생 기록 조회·과제 관리·설정·CSV 내보내기 |

## 🚀 배포 방법 (Google Apps Script)

### 1단계 — 구글 시트 + Apps Script 프로젝트 생성

1. [Google Sheets](https://sheets.google.com) 에서 새 스프레드시트 생성
2. 메뉴 **확장 프로그램 → Apps Script** 클릭
3. 프로젝트 이름을 `글쓰기코칭시스템` 으로 변경

### 2단계 — 코드 붙여넣기

1. Apps Script 편집기에서 기본 `Code.gs` 내용을 모두 지우고  
   이 저장소의 `Code.gs` 내용을 붙여넣기
2. 좌측 파일 목록 **＋ → HTML** 클릭 → 파일명 `index` 입력  
   (`index.html` 이 아닌 `index` 만 입력)
3. `index.html` 내용을 붙여넣기
4. **💾 저장** (Ctrl+S)

### 3단계 — 웹앱 배포

```
Apps Script 편집기
→ 오른쪽 상단 [배포] 버튼
→ [새 배포]
→ 유형 선택: 웹 앱
→ 설명: v1.0
→ 다음 사용자로 실행: 나 (본인)
→ 액세스 권한: 모든 사용자 (로그인 필요 없음)
→ [배포] 클릭
→ 웹앱 URL 복사
```

> ⚠️ **코드 수정 후**에는 반드시 **[배포 → 기존 배포 관리 → 편집 → 버전: 새 버전]** 으로 재배포해야 변경이 반영됩니다.

### 4단계 — 시트 자동 초기화 확인

웹앱 URL 접속 시 자동으로 아래 4개 시트가 생성됩니다:

| 시트 이름 | 용도 |
|---|---|
| 설정 | API 키, 관리자 비밀번호, 학교명 등 |
| 과제목록 | 과제 ID, 제목, 글쓰기 유형, 대상 학년 |
| 학생작성글 | 개요·초고·수정글·제출 여부 등 전체 기록 |
| 활동로그 | 저장·제출 등 학생 활동 타임스탬프 |

### 5단계 — Gemini API 키 설정

1. [Google AI Studio](https://aistudio.google.com/app/apikey) 접속
2. **Create API Key** 클릭 → 키 복사
3. 웹앱 접속 → **관리자 로그인** (초기 비밀번호: `admin1234`)
4. **설정 탭 → Gemini API 키** 항목에 붙여넣기 → 저장

## 👩‍🏫 사용 방법

### 학생

1. 웹앱 URL 접속
2. 학년 / 반 / 번호 / 이름 입력 후 **시작하기**
3. 과제 선택 (이전 작업이 있으면 자동 복원)
4. 단계별 진행:

```
① 개요 작성  →  ② 개요 수정  →  ③ 글쓰기
→  ④ 제출  →  ⑤ 고쳐쓰기  →  ⑥ 최종제출
```

5. 각 단계에서 **AI 코치**에게 질문하거나 피드백 요청 가능

### 교사 (관리자)

1. 로그인 탭에서 **관리자** 선택
2. 비밀번호 입력
3. 대시보드에서 전체 현황 확인
4. 학생 기록 탭에서 학년·반 필터 후 개별 글 열람
5. CSV 내보내기로 엑셀 분석 가능

## ❓ 자주 묻는 질문

**Q. API 오류 429가 계속 뜹니다.**  
A. Gemini 무료 티어의 분당 요청 한도 초과입니다.  
잠시 기다리거나 [Google AI Studio](https://aistudio.google.com) 에서 새 API 키를 발급받으세요.  
또는 Google Cloud Console에서 결제 수단 등록 시 한도가 대폭 늘어납니다.

**Q. 코드 수정 후 변경 사항이 반영이 안 됩니다.**  
A. Apps Script는 반드시 **재배포** 해야 합니다.  
`배포 → 기존 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포`

**Q. 시트가 생성되지 않습니다.**  
A. 웹앱 URL로 직접 접속하면 자동 생성됩니다.  
Apps Script 편집기에서 `doGet` 함수를 직접 실행하지 마세요.

**Q. 학생이 이름을 숫자로 입력하면 기록이 안 불러와집니다.**  
A. 최신 버전에서 수정 완료되었습니다. (String 타입 통일 처리)
