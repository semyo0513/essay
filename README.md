# ✏️ 창순기획 글쓰기 코칭 시스템 (Serverless Version)

> **서버가 필요 없는 단일 파일 HTML 기반 중학교 글쓰기 코칭 웹앱**  
> 학생은 단계별로 개요와 글을 작성하고, 브라우저에서 직접 Google Gemini AI 코치의 실시간 피드백을 받습니다. 작성 완료된 글은 JSON 파일로 저장·제출하며, 교사는 이를 일괄 취합하여 한눈에 확인하고 평가할 수 있습니다.

---

## 📌 주요 특징 및 기능

| 기능 | 설명 |
|---|---|
| 📝 **단계별 글쓰기 코칭** | 개요 작성 → 개요 수정 → 초고 작성 → 1차 제출 → 고쳐쓰기 → 최종 제출 (총 6단계)의 체계적 프로세스 |
| 🤖 **AI 챗봇 코치** | Google Gemini API (기본 `gemini-2.5-flash` 모델 권장) 연동을 통한 실시간 1:1 맞춤 피드백 및 글쓰기 지도 |
| 📚 **다양한 글쓰기 유형** | 주장하는 글 / 설명하는 글 / 감상문 / 정보전달글 기본 탑재 (관리자 페이지에서 과제 추가/삭제 가능) |
| 💾 **로컬 자동 저장** | 브라우저 LocalStorage를 통한 자동 저장 기능으로 창을 닫거나 컴퓨터가 꺼져도 작성 내용 안전하게 복구 |
| 📥 **JSON 기반 과제 제출** | 네트워크 서버나 DB 구축 없이 학생이 자신의 작성 기록을 `.json` 파일로 직접 다운로드하여 제출 |
| 🗂️ **교사 관리 대시보드** | 학생들이 제출한 다수의 JSON 파일을 드래그 앤 드롭으로 한번에 불러와 현황 파악, 상세 비교(초고 vs 수정글) 및 CSV 다운로드 |
| ⚙️ **사용자 맞춤형 설정** | 학교명, 앱 타이틀, 관리자 비밀번호, 사용하고자 하는 Gemini 모델을 브라우저에 개별 저장하여 즉시 적용 |

## 🛠️ 기술 스택

```
Frontend   index.html (HTML5, CSS3, Vanilla JS, Google Fonts, Marked.js 패키지)
Database   Web LocalStorage (브라우저 로컬 데이터 저장)
AI Client  Google Gemini API (Direct Browser Request)
Deployment 정적 웹 호스팅 (GitHub Pages, Netlify, Vercel 등) 또는 로컬 단독 실행
```

## 🚀 사용 및 배포 방법

### 1단계 — 실행 및 배포
본 시스템은 백엔드 서버나 DB 설치가 필요하지 않습니다.
* **방법 A (로컬 실행)**: `index.html` 파일을 학생 및 교사 컴퓨터에 복사한 뒤 더블 클릭하여 웹 브라우저(크롬, 엣지 등)로 실행합니다.
* **방법 B (웹 배포)**: GitHub Pages, Netlify, Vercel 등 무료 정적 웹 호스팅 서비스를 이용하여 `index.html`을 업로드하면 웹 주소(URL)를 통해 어디서나 간편하게 접속할 수 있습니다.

### 2단계 — 교사/관리자 초기 설정
1. 웹앱 우측 상단의 **[관리자 로그인]** 버튼을 클릭합니다.
2. 초기 관리자 비밀번호인 `admin1234`를 입력하여 로그인합니다.
3. **[설정]** 탭으로 이동하여 아래 항목들을 설정합니다.
   * **Google Gemini API Key**: [Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료로 발급받은 API 키를 입력합니다. *(필수)*
   * **Google Gemini 모델 선택**: 기본값인 `gemini-2.5-flash`를 권장합니다. (필요 시 `gemini-1.5-flash`, `gemini-1.5-pro` 선택 가능)
   * **학교명 & 앱 타이틀**: 해당 학교 환경에 맞게 학교명과 제목을 수정합니다.
   * **관리자 비밀번호**: 안전한 비밀번호로 변경하여 저장합니다.
4. **[과제 관리]** 탭으로 이동하여 학생들이 작성할 글쓰기 과제를 생성하거나 기본 과제를 확인합니다.

> 💡 **중요**: 관리자 설정값은 브라우저의 `LocalStorage`에 저장됩니다. 공용 컴퓨터 실습실의 경우, 교사용 메인 컴퓨터 브라우저에서 설정해 두거나 학생 컴퓨터별 브라우저에서 API Key 설정을 완료해야 Gemini AI 기능이 원활히 동작합니다.

### 3단계 — 학생 글쓰기 진행
1. 학생들은 웹앱에 접속한 후 자신의 **학년 / 반 / 번호 / 이름**을 입력하고 **[시작하기]**를 누릅니다.
2. 교사가 사전에 등록해 둔 **과제 목록** 중 원하는 과제를 선택합니다.
3. 화면의 안내에 따라 개요와 본문을 작성하며 우측의 **[AI 코치]**에게 실시간으로 피드백을 요청하여 글을 다듬습니다.
4. **4단계(1차 제출)** 또는 **6단계(최종 제출)**에 도달하면 **[제출 파일 다운로드]** 버튼이 활성화됩니다.
5. 학생들은 이 버튼을 눌러 생성된 학년-반-번호-이름 형식의 `.json` 파일을 다운로드하여 교사에게 제출(LMS, 이메일, USB 등 활용)합니다.

### 4단계 — 교사 과제 취합 및 평가
1. 교사는 관리자 페이지로 로그인한 후 **[학생 기록]** 탭으로 이동합니다.
2. 학생들로부터 전달받은 `.json` 파일들을 화면 중앙의 **드롭존(Dropzone)**에 일괄 드래그 앤 드롭하거나 파일 선택기로 한꺼번에 업로드합니다.
3. 업로드 즉시 제출 학생들의 학년·반·번호 순서대로 명단이 정렬되며, 제출 상태, 최종 수정일, 현재 진행 단계가 한눈에 표시됩니다.
4. 명단 우측의 **[보기]** 버튼을 클릭하면 해당 학생이 작성한 개요와 초고, 그리고 수정글이 일목요연하게 비교되는 상세 모달 창이 열립니다.
5. **[CSV 파일로 내보내기]**를 클릭하면 모든 학생의 글 내용과 피드백 상태가 담긴 엑셀 호환 CSV 파일을 다운로드할 수 있어 손쉬운 평가가 가능합니다.

## ⚙️ 관리자 설정 세부사항

| 설정 키 | 기본값 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | (없음) | AI 피드백 생성을 위한 구글 AI Studio API 키 **(필수 입력)** |
| `GEMINI_MODEL` | `gemini-2.5-flash` | 사용되는 Gemini 모델 (`gemini-2.5-flash`, `gemini-1.5-flash`, `gemini-1.5-pro` 선택 또는 직접 입력) |
| `ADMIN_PASSWORD` | `admin1234` | 관리자 대시보드 접근 비밀번호 |
| `SCHOOL_NAME` | 삼현여자중학교 | 헤더 좌측에 노출되는 소속 학교명 |
| `APP_TITLE` | 글쓰기 코칭 시스템 | 헤더 중앙 및 브라우저 탭에 표시되는 제목 |

## ❓ 자주 묻는 질문 (FAQ)

**Q. 입력한 API Key는 보안상 안전한가요?**  
A. 예, 입력된 API Key는 서버나 외부로 절대 유출되지 않으며 오직 사용자 브라우저 내부의 로컬 스토리지(`LocalStorage`)에만 저장됩니다. Gemini AI 요청 역시 브라우저에서 구글 API 주소로 직접 암호화 통신합니다.

**Q. API 429 에러(Quota Exceeded)가 발생합니다.**  
A. Gemini API 무료 티어(Free tier)는 분당 요청 횟수(RPM)에 제한이 있습니다. 학급 전체 인원이 동시에 피드백 버튼을 누를 경우 일시적으로 한도가 초과될 수 있으니 10~20초 뒤 다시 시도하게 하거나, Google Cloud 결제 수단을 등록하여 종량제(Pay-as-you-go) API 키를 사용하시면 해결됩니다.

**Q. 학생들이 새로고침을 하거나 창을 닫으면 작성하던 글이 날아가나요?**  
A. 아닙니다. 브라우저 로컬 저장소에 글자가 입력될 때마다 실시간으로 자동 저장이 작동하고 있어, 컴퓨터가 꺼지거나 새로고침을 하더라도 학년/반/번호/이름을 똑같이 입력하고 들어가면 이전 작성 내용이 그대로 복원됩니다.

**Q. 학생들의 글이 교사 대시보드에 실시간으로 보이지 않습니다.**  
A. 본 시스템은 데이터베이스 서버를 두지 않는 완전 정적(Static) 파일로 설계되어 있습니다. 따라서 실시간 원격 모니터링은 불가능하며, 학생들이 다운로드한 `.json` 파일을 한데 모아 교사 컴퓨터의 관리자 화면에 업로드(취합)해 주셔야 합니다.

## 🔄 업데이트 이력

* **v2.0 (현재 버전)**
  * **Serverless 아키텍처 전환**: 기존 Google Apps Script(`Code.gs`) 및 Google Sheets 데이터베이스 구조를 완전히 걷어내고, Browser `LocalStorage`와 `JSON` 파일 다운로드/업로드 방식으로 전면 전환하여 서버 설치와 연결의 번거로움을 제로화했습니다.
  * **최신 Gemini API 모델 지원**: `gemini-2.5-flash` 모델을 권장 모델로 탑재하였으며, 관리자 화면에서 간편하게 모델을 선택하거나 커스텀 모델명을 직접 지정할 수 있도록 개선했습니다.
